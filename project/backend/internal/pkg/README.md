# Общие внутренние компоненты

Здесь размещается код, который используют несколько сервисов RepoPulse:

- `adapter/in/kafka` — общие Kafka consumers;
- `adapter/out/kafka` — общие Kafka producers;
- `adapter/out/repository` — общие механизмы доступа к хранилищам;
- `adapter/out/<client_name>` — общие внешние клиенты по мере появления.

Каталоги адаптеров зарезервированы для дальнейшей реализации. Доменные модели
и сервисные реализации остаются в `internal/<service>`. Утилита контекстного
логгера находится в `libs/logger` согласно решению ревью.
